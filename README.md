# Agenda de Contactos con PHP y MySQL

**Materia:** Programación Web
**Integrantes:** Ramírez Ovilla Luz María del Consuelo,Ramses Figueroa Santiz, Domínguez Chacón Diany Briggith

## Descripción
Aplicación web para gestionar una agenda de contactos con operaciones CRUD completas.

## Tecnologías
PHP 8, MySQL/MariaDB, PDO, HTML5, CSS3

## Funcionalidades
- Crear, listar, ver, editar y eliminar contactos (CRUD completo)
- Foto de contacto
- Búsqueda de contactos
- Validación en cliente y servidor
- Sentencias preparadas, htmlspecialchars y token CSRF

## Instalación
1. Importar `database.sql` en MySQL.
2. Copiar `config/db.example.php` a `config/db.php` y poner tus credenciales.
3. Dar permisos de escritura a la carpeta `archivos/`.
